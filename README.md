# Unreal Engine 5.4 项目

这个仓库包含一个使用 Unreal Engine 5.4 开发的游戏项目。

## 项目说明

这是一个作品集游戏制作项目，使用 Unreal Engine 5.4 开发。

## 开发环境

- Unreal Engine 5.4
- 推荐使用 Visual Studio 2022 或更高版本

## 如何使用

1. 克隆此仓库
2. 使用 Unreal Engine 5.4 打开项目文件
3. 根据需要编辑和构建项目

## 注意事项

- 大型二进制文件和中间文件已通过 .gitignore 排除，不会被提交到仓库中
- 请确保在提交前查看 .gitignore 文件，了解哪些文件不会被包含在版本控制中
